Using your second monitor

Start at 1024×768. In KDE System Settings → Display Configuration, arrange Side-Panel beside your main display and apply. Drag a window onto it using your PC mouse. Touch control is optional.

Use Stop display before leaving. Returning to Deck or closing Safari keeps the virtual monitor alive so windows stay in place. Stop the companion with Ctrl+C to remove it. Safari fullscreen varies by iPad/iOS version; Add to Home Screen is an alternative. Double-click/touch input and sleep recovery need hardware testing.
